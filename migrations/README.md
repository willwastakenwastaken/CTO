# Migrations

SQL migrations live here (plain SQL files, applied in order, e.g. `0001_init.sql`).

Phase 1 currently has **no migrations**: Supabase is not connected yet (the
owner must provision a project and provide `NEXT_PUBLIC_SUPABASE_URL` and
`NEXT_PUBLIC_SUPABASE_ANON_KEY`). The schema milestone will add:

- `profiles`, `sales_profiles`, `prospects`, `prospect_notes`, `activities`,
  `call_sessions`, `transcript_segments`, `call_events`, `ai_suggestions`,
  `product_events`
- UUID primary keys generated by Postgres; IDs stay strings everywhere
- Enum checks, score/confidence ranges, nonnegative times, indexes, update
  triggers, idempotency constraints
- RLS enabled on EVERY user-owned table (`auth.uid()`), including related
  ownership verification — User A must never access User B's data
